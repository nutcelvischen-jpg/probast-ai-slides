## ⌨️ Presentation Shortcuts

| Key / Action | Function |
| :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> / Wheel Down | Advance to next slide / step |
| <kbd>←</kbd> / Wheel Up | Go back to previous slide |
| <kbd>P</kbd> | **Launch Presenter Mode** (dual-screen teleprompter, rehearsal timers, next-slide preview) |
| <kbd>B</kbd> | **Toggle Low-Power Mode** (halts WebGL shaders & transitions, displays clean static typography) |
| <kbd>ESC</kbd> | Toggle full slide thumbnail overview |
